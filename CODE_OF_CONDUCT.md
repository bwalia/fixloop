# Code of Conduct

Fixloop follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

Please report instances of abusive, harassing, or otherwise unacceptable behaviour to the project maintainers listed in [MAINTAINERS.md](MAINTAINERS.md). If the matter involves a maintainer, or you do not get a response, contact the CNCF Code of Conduct Committee at <conduct@cncf.io>.
